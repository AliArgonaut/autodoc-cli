# Auto-Doc CLI

Auto-Doc is a powerful command-line interface tool designed to automate the process of generating documentation and creating comprehensive markdown files for your projects. It leverages AI to analyze your codebase, understand its structure, and produce high-quality documentation.

## Introduction

Auto-Doc aims to streamline the documentation workflow for developers. By integrating with an AI backend, it can take a snapshot of your workspace, analyze your code, and generate detailed documentation, including a polished README file. This ensures your project is well-documented, making it easier for collaborators and future you to understand and maintain.

## Features

- **Project Initialization:** Easily set up a new documentation project with a configuration file.
- **Automated Documentation Generation:** Send your project's structure and code to the AI backend for comprehensive documentation generation.
- **Health Check:** Verify the connectivity and operational status of the Auto-Doc AI agent backend.
- **Code Analysis:** Analyzes supported programming languages (`.jsx`, `.py`, `.tsx`, `.go`, `.cpp`, `.java`, `.js`) to extract relevant information.
- **Configurable Ignore Patterns:** Specify files and directories to be excluded from the documentation process.

## Installation

To install the Auto-Doc CLI, you'll need to have Go installed on your system.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your_username/auto-doc.git
    cd auto-doc/cli
    ```

2.  **Build the executable:**
    ```bash
    go build -o auto-doc .
    ```

3.  **Run the executable:**
    The `auto-doc` executable will be created in the current directory. You can then use it from your project's root directory.

## Usage

The Auto-Doc CLI provides several commands to manage your documentation process.

### Initializing a Project

To start a new documentation project, use the `init` command. This command sets up the necessary configuration file (`autodoc_config.json`) with default settings.

```bash
./auto-doc init
```

This will:
- Contact the backend API to retrieve a template for `autodoc_config.json`.
- Create the `autodoc_config.json` file in your current directory.

### Generating Documentation

Once your project is initialized, you can generate documentation using the `generate` command. This command sends your project's file structure and code content to the AI backend for processing.

```bash
./auto-doc generate
```

This command will:
1.  Determine the current working directory.
2.  Read your `autodoc_config.json` file to get project details (name, description, ignore patterns).
3.  Build a file tree representation of your project, excluding ignored files.
4.  Identify and read the content of supported language files.
5.  Construct a request payload with project information and code content.
6.  Send the payload to the backend API at `http://localhost:8000/api/generate`.
7.  Receive and display the generated documentation from the backend.

### Checking Backend Health

To ensure the Auto-Doc AI backend is running and accessible, use the `health` command.

```bash
./auto-doc health
```

This command will:
1.  Ping the backend API at `http://localhost:8000/api/health`.
2.  Display the status response from the backend, helping you troubleshoot connectivity issues.

## Configuration

The `autodoc_config.json` file is used to configure your Auto-Doc project. It is generated by the `init` command and can be manually edited.

```json
{
  "name": "my config",
  "developer": "Your Name",
  "description": "this is the default auto-doc config file generated by Agentia",
  "ignore": [
    ".git",
    "node_modules",
    "vendor"
  ]
}
```

-   **`name`**: The name of your project.
-   **`developer`**: The name of the developer or team.
-   **`description`**: A brief description of the project.
-   **`ignore`**: A list of file or directory names/patterns to exclude from documentation generation.
